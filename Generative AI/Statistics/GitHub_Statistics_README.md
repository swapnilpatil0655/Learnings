- 📥 Collection of Data

- 🧠 Interpretation of Data
- 📈 Presentation of Data

# 📚 Important Statistical Concepts

## 1️⃣ Mean

### Definition
Average value of data.

### Formula

```text
Mean = Sum of Observations / Total Observations
```

### Purpose
Represents the central tendency of data.

---

## 2️⃣ Median

### Definition
Middle value of sorted data.

### Purpose
Useful when data contains outliers.

---

# 📈 Data Distribution

Statistics helps understand how data is distributed.

## 📌 Types of Distributions

- Gaussian Distribution
- Normal Distribution
- Standard Normal Distribution
- Log Normal Distribution

---

# 📊 Data Visualization

## 1️⃣ Histogram

A histogram uses vertical bars to represent frequency distribution.

### Purpose
- Understand data spread
- Identify patterns
- Visualize frequency

---

## 2️⃣ PDF (Probability Density Function)

A smooth probability distribution curve derived from histogram data.

---

## 3️⃣ CDF (Cumulative Density Function)

Represents cumulative probability up to a specific value.
